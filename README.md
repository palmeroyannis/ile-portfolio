# Portfolio jeu vidéo

Jeu 3D en Rust (Bevy 0.19) jouable dans le navigateur, qui sert de portfolio.

## Lancer

Dans le navigateur (recompile à chaque modification) :

    trunk serve --open

En fenêtre Windows classique (plus rapide pour tester) :

    cargo run

## Mettre en ligne

    trunk build --release

Le site à publier est généré dans le dossier `dist`.
